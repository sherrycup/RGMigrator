# 0.55 标题原图恢复

本版按正式 Scripts.rxdata 导出的最终0139—0145及0111的有效代码恢复标题。原工程只读；展开Scripts镜像用于结构参考。640×640、60Hz；输入和过渡由标题或各附页各自的唯一时钟推进。

- 背景为原480张图；保留最多32张实例缓存、8个异步请求。标志原尺寸480×320，16帧入场。
- 七条命令使用原com_0—6图片，五个循环槽位，16帧移动、缩放、透明度插值。独立副本和无有效存档的继续游戏允许选中、灰显并拒绝确认；有有效存档默认选中继续游戏。
- 四张原Mode_1—4难度卡片沿224×192斜向排列，默认Hard，返回后保留选择；EX沿用源半透明规则但可开始。确认仍由Title初始化同一RuntimeState并写DIFFCULTY_MODE（实际141），不创建替代状态。
- 附页与命令反向16帧进入/返回；原320×48页签从右进入。新游戏/读档提交期间拒绝重复提交，读档失败后释放输入。
- 设置页使用原标签、音量槽、四角光标和渐变线框；写同一FlashPreferences，音量0—10、窗口大小、奔跑按键保持。Q/E切三页，后两页按源保留未完成内容。
- 音乐页恢复原唱片、唱针、28帧移动和逐帧旋转及十份Info。get_new_bitmap原本为空；切换索引不会切曲、试听或修改正在播放的标题BGM。
- 成就页恢复四分类、摇摆/升降、说明滑动、书本和示例文本；原书页是重复示例，无解锁或发奖实现。本版不会发放示例中的200金币。

方向键移动，Enter/Z/空格确认，Esc/X返回；难度上下左右，音乐上下，成就四方向；设置Q/E翻页。过渡期间输入不提交新动作。正文与原素材比较依据为最终有效代码和资源，未取得原RGSS运行截图作逐像素对照。档案卡片完整恢复在0.56；菜单与其它功能页分别在0.56—0.57。

主要接口见05_Title各脚本的中文文件头；FlashTitleLayout只计算原坐标与插值，FlashTitleScreen管理标题输入和页面生命周期，Title仍处理新游戏/正式读档。测试与截图证据见tests/VERIFICATION_v0.55.md。用户人工验收集中在后续版本，内部验证不代表完整剧情通关。

文字适配：标题附页的原draw_text宽度在Godot使用水平压缩，保留字号高度，避免Lunatic或中文尾字被裁掉。原未接入的sign示例沿用已迁移的可读显示，文本下移24像素到书本纸面内；没有新增奖励和解锁逻辑。
