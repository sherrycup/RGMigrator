# 0.56 主菜单与档案恢复

按正式Scripts.rxdata最终0111、0139、0170—0173、0181、0186、0198及0200—0203恢复。标题、菜单、档案由用户之后统一人工验收，本版只记录内部验证。

菜单使用原两行错位文字、英文底字、独立渐亮选中层、下划线、锁定项以及五色耀晶石和Point窗口；原8帧移动和透明度。打开菜单时原地图HUD收起，底层保留暂停的同一地图，不把存档截图当成带HUD的模糊背景。原空装备、成就、合成分支保持；功能页完整图形继续0.57。

档案按原多窗布局从上下左右进入：原章节、模式、120×64卡片、240×256裁切视口、独立四角光标、352×352截图框及316×316预览、480×128人物摘要。目录只在显式刷新时核对，移动光标复用缓存与节点；八帧选择与截图合成各有自己的进度。原上下连续、左右按列与剩余行循环；Tab切模式的原8帧过渡保留。标题使用原左侧章节和8像素文件栏位置，档案与Load Data页签按原8帧进入，页签每帧40像素/32透明度；标题主命令仍独立16帧退场；菜单用原右侧章节及16像素文件栏位置，不重复推进父动画。

读写使用同一SaveService及Game.save_slot；覆盖/备份确认改为原图风格绘制，缺图、空槽、损坏、拒绝保存均有反馈。一次确认只提交一次；失败恢复输入，成功按原8帧退场后恢复同一地图暂停和事件调用者。截图取菜单打开前完整地图，人物与章节来自所选档案自身的校验快照，不读取当前角色冒充旧档。

源Window_FileTips未在最终地图/标题实例化，取消旧移植额外显示的示例Tips；仅在空白区域展示真实读写失败信息。原“自动存档档案编号”标签没有自动保存实现，本版仅保留显示、不新增自动保存。章节0/1沿用原“摸鱼”和删除线，后续章节原未绘制内容不补造。原存档变量/循环关系及JSON兼容校验保持，原RM只读，不读取RM旧存档。

主要脚本：FlashMenuScreen负责菜单输入与子页生命周期；FlashArchivePage负责目录、选择和请求；FlashArchiveView只读绘图；FlashWindowDrawing提供原渐变面板、文字横向适配和四角光标。每个文件头说明实际接口、参数和返回。比较依据为原有效源码和素材，未取得原RGSS运行截图作逐像素对照。

关闭请求在大delta补帧或持有方稍后释放节点时只发出一次；关闭标志在信号之前设置，防止重入。
