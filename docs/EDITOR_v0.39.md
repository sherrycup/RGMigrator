# ver0.39 编辑器交互与指令配色

本版合并0.38已记录的交互优化和0.39指令配色。数据库、地图和事件继续只编辑草稿，Ctrl+S保存文件后重新运行游戏读取定义。

- 数据库顶部“设置最大编号…”一次扩展编号范围，新增编号显示为空槽位。例如最大编号200改为500，可直接跳转到350编辑，中间保持空白。编号0保留，已有条目不重新编号；空槽位实际编辑才建立默认定义。最大编号范围1–32767，缩容检查内容和引用，测试物资占用编号标为“测试保留”。
- 数据库列表每组100条，箭头切组，编号输入框加“跳转”直接定位；搜索跨全部编号范围。系统开关/变量/属性名称页提供相同容量和跳转操作，未命名编号可以保留。
- 顶部“应用条目”按钮已移除。切换条目、关闭窗口会校验并保留当前修改到共享草稿；Ctrl+S才写文件。撤销可以恢复修改。关闭不表示放弃草稿，校验失败会保持编辑窗口并说明原因。
- 动画选择其它条目、保存、切换分类后返回，会保留“动画编辑”等有效用途页签。新动画替换旧预览；默认单次播放及音效试听规则沿用0.37。
- 公共事件的名称、触发方式和开关放在紧凑顶部区域，下面的事件指令列表占主要编辑空间。
- 图块属性符号按放大后的实际格子尺寸重绘：圆圈/叉号、方向箭头和星形是独立几何图案，地形等文字按实际字号居中。图块图片继续保持像素显示，标记不随小尺寸字体一起粗糙放大。
- 地图绘制工具栏不再提供吸管按钮和I快捷键；绘制模式下右键拾取当前图层图块并切回铅笔。事件模式右键仍打开事件和起点菜单。
- 地图事件、公共事件、移动路线共用功能配色。文本为蓝青色、流程为蓝紫色、开关/变量为橙色、移动为绿色、画面为紫色、音频为青绿色、角色为粉色、物品/金钱为黄色、注释为灰绿色；脚本占位及未支持指令保留状态文字与暖色提示。浅色主题使用更深的对应颜色，选中状态使用主题对比文字。
- 文章和注释只在第一行显示“显示文章：”或“注释：”，后续行的正文与首行冒号后的正文起点对齐，整段使用相同类别色。对齐按当前字体与字号测量，条件分支缩进标记保持原位。左侧竖线连通同一条指令的全部行，指令之间留出间隔。点击首行、续行或空白续行，整条指令以连续蓝底白字选中；上下键切换整条指令，双击打开全文，复制/删除/粘贴/上下移动作用于完整指令，原始编号、参数和换行保持。地图事件和公共事件共用此行为。

验收工程从两个原RM工程重新迁移至 `../output/0.39/command-blocks/`，历史输出保留。验证及性能记录见 [ver0.39验证记录](../tests/VERIFICATION_v0.39.md)，本次修正见[多行指令整体选择修正记录](../tests/VERIFICATION_v0.39_command_blocks.md)。
