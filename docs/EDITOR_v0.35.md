# ver0.35 事件编辑与素材选择

0.34与0.35合并交付为ver0.35。打开生成工程的`project.godot`，进入“魔塔编辑器”；点击“编辑事件”，双击地图格子打开事件窗口。

事件窗口顶部是事件页签，提供新建、复制、删除和左右移动。左侧按出现条件、图形、自主移动、选项与触发分组；下方内容可滚动。开关和变量按钮显示名称与编号，点击后可搜索选择；条件开关关闭时对应参数禁用，原值仍保留。右侧编辑当前页的事件指令。切换页签保留各页草稿；满足条件时仍由编号最大的页生效。

点击右侧“添加”，打开三页按钮菜单：消息与流程、地图与画面、角色与场景。选择按钮后编辑该指令参数，“选择其他指令”可返回菜单。地图与公共事件共用菜单；已有指令直接打开参数窗口。条件、变量和地图画面子类型仍会更新对应参数，209路线保留专用动作按钮和路线列表。图形区直接设置混合方式。原“更多原始字段”曾是同一事件页的完整表单，没有额外事件功能；现改为“工程扩展字段”，只显示原工程自定义的额外字段，没有扩展时隐藏，常用属性不再重复。应用扩展字段仅修改这些附加数据，不执行原工程脚本。

行走图、图片、图标、图块集图像等图片字段使用带边框的棋盘预览框，分别显示固定用途标题、简短说明、素材名和“双击更换素材”。角色行走图与战斗图分别标明地图外观、战斗外观；普通图块主图、自动图块1–7、全景、雾及战斗背景逐项标明用途，未加载素材的槽位仍显示标签。战斗图/背景继续保留为元数据。双击预览定位当前素材；也可双击表格中的图片字段打开同一窗口。输入名称搜索，左侧显示每组最多80个缩略图，右侧显示大图。“原图尺寸”可查看并滚动原图，关闭后适应窗口。当前缺失的素材名称仍显示并保留，不会自动换成第一项。

行走图按原RMXP的4×4结构显示。点击网格选择方向和图案帧，黄色边框标记所选格；下、左、右、上分别对应原方向2、4、6、8，表单帧编号为0–3，选择窗口说明使用第1–4帧。事件图形和移动路线会保存对应方向/帧；数据库角色图形没有这两个原生字段，网格用于查看。色相与不透明度即时预览，只有原数据包含的相关字段或指令参数会写回。

事件图形区提供“行走图素材…”和“当前地图图块…”按钮。后者显示本地图绑定的数据库图块集名称与编号，点选普通图块可作为事件外观；“清空图形”按钮清除外观。当前为图块图形时，双击预览打开图块选择窗口并定位原图块；选择行走图确认后图块编号归0。图块图形沿用原生tile_id，取消保留原图；不修改地图铺设或图块属性。

素材窗口确认后更新当前表单草稿；取消保留原图。地图事件还需点击“应用事件”，数据库条目需点击“应用条目”或“应用并关闭”，最后按Ctrl+S保存工程数据。共享原图片不改写，保存沿用备份、撤销/重做与外部变更检测。

本版完整指令配色仍留到0.39；多图片图块集组合、逐格图块属性和可扩展图层在0.36。
