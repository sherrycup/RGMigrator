# 0.58 UI验收修正

2026-10-19按用户反馈实施，版本仍为0.58。

- 物品页最右侧1—9格物品预设栏取消外层背景窗口，保留原格框、图标、数量、按键编号、选择光标及进退效果。分类、物品列表、说明窗口不变。
- 在Godot编辑器运行游戏，进入地图后按F7开启援护UI预览，再按F7关闭。预览期间画面左上显示“援护UI预览 · F7关闭”；技能配置页沿用同一HUD，可在该页切换F7。按键长按不会重复切换。
- 默认关闭；新游戏、读档或回标题后关闭。正式援护已解锁时始终显示真实角色及数值，F7关闭不会隐藏正式援护。原事件验收地图继续保留其F7退出功能。

这是临时显示开关。援护尚未入队时，默认读取原角色3芙涅莉可的图像及初始化预设（8级、HP3200/4000）；若角色3是当前主战，改用原角色2，避免同一人重复。已有角色读取其当前数值，否则HUD私有创建脱离现场的显示角色；不注册到RuntimeState.actors，不改队伍、解锁开关、角色顺序、技能或战斗，不参与物品目标选择，也不写入存档。原未完成BUFF区域保留空白。

调用入口：`FlashPlayerHUD.set_support_preview(enabled: bool) -> bool`，参数为期望的开关状态，返回本HUD实际启用状态；通常直接使用F7。`RuntimeState.execution_reset`清除开关和显示角色；HUD销毁后无全局残留。F7仅在调试运行、当前闪翼地图生效。

维护源码为`templates/runtime/scripts/08_Menu/Item/FlashItemView.gd`和`templates/runtime/scripts/03_Map/FlashPlayerHUD.gd`。正式工程从原RM重新导出到`../../output/0.58/ui-review/`，旧最终归档在新交付完整核验后替换，用户旧工程修改须保留。

自查记录见[本轮验证](../tests/VERIFICATION_v0.58_UI.md)；此前0.58完整回归见[主验证](../tests/VERIFICATION_v0.58.md)，不可将原完整回归视作本轮所有场景重新执行。
