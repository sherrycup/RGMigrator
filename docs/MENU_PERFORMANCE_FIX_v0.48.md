# 0.48 菜单按键卡顿修复

2026-10-15。范围为当前简化界面的按键与刷新性能；原工程图形 UI 还原已按用户确认安排至 0.5，见 UI_OPTIMIZATION_v0.5.md。本次保持 0.48，0.49 整体验收仍未完成。

## 原因与处理

- 标题移动原先重建七个按钮并调用 has_valid_save，每次都读取存档并同步执行 SaveCodec.prepare。现在移动仅更新选中状态；难度、设置、物品、技能、笔记、回路同链孔位和独立选择页也复用未变化的控件。
- 存档页原先每次移动重读所有槽位并重建页面。现在进入/显式刷新读取摘要，移动复用卡片、角色控件、目录快照和缩略图；换可见区时才重建卡片。
- SaveService 只缓存已完整验证的展示摘要，按工程、数据指纹、主文件与备份的实际字节 SHA 区分，最多 16 条。返回可变容器独立，成功保存及时更新；同秒同长度外部修改也会失效。read_slot/load_slot 始终重新读文件并完整验证，不使用展示缓存安装状态。
- 存档八帧渐变改为独立 SubViewport 内两张纹理的透明度合成，保留 352 画布、316 截图及 10 像素内边距，缩略图最多缓存 8 张。快速切换截取当前合成图继续渐变；每帧不再在 GDScript 中遍历约十万至二十万像素、重新缩放和上传纹理。
- 标题 480 帧装饰背景采用线程资源请求，最多 8 个待载入、32 张保留纹理；主线程只领取已完成资源，未完成时沿用上张画面，时钟仍推进。避免按键长帧引起背景补帧加载、进一步延长下一帧的循环。
- 闪翼直接脚本执行、报错弹窗后退出、事件前撤回验证与原事件等待保持。

## 验证方式

FlashMenuNavigationTests 使用隔离存档检查真实写入、摘要隔离、同秒同尺寸修改、损坏拒绝、备份、原八帧渐变及中途切换，并检查页面状态和控件复用。GPU 路径另检查实际预览像素。

FlashMenuPerformanceProbe 用现有用户存档的只读副本，对相同正式运行时前后顺序测量直接按键回调、实际 Title 输入分发、动态背景、存档切换和快速中断渐变。游戏运行使用 Compatibility/GTX1660Ti；离屏 QA 关闭 VSync，正式设置保持。用户存档及历史输出不修改。最终数值与正式导出复核完成后追加。
