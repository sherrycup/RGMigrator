本次合并交付0.30名称/枚举统一和0.31事件摘要。本版继续使用现有窗口结构。用户反馈后重新安排：0.32/0.33优先完成地图编辑基础与制作工具，RM分类页签＋按钮式事件菜单改为0.34，双击图片替换改为0.35，完整事件指令分类配色放到0.39。当前计划见[0.3计划](UI_ROADMAP_v0.3.md)。

## 名称、编号和选择

事件页条件、事件指令、移动路线、地图属性与数据库引用显示“名称 [编号]”。名称读取当前编辑草稿，改名、应用、撤销/重做后同步刷新；编号不变。没有名称显示“未命名 [编号]”，引用不存在显示“缺失引用 [编号]”。

双击引用字段，在搜索框输入名称或编号，在列表中选择。可以保留或手动输入原始编号，选择名称只修改数字ID。全体队员、卸下装备、无动画、无父地图和无引用按字段实际含义显示，不把所有编号0都解释成同一个对象。未知枚举或历史异常编号打开后直接确认仍保留原值。

开关开启/关闭、变量操作/操作数、触发方式、方向、图片原点/混合、角色槽位和商店商品类型显示具体含义。变量来源改变时，比较值、增减数量和传送坐标等字段同步切换为变量名称。公共事件触发0无/1自动/2并行仍与地图五种触发方式分别处理。

## 事件列表

地图事件和公共事件共享摘要：

| 指令 | 显示示例 |
| --- | --- |
| 操作开关 | 开启开关 剧情开始 [0001] |
| 操作变量 | 变量 钥匙数量 [0002] += 10 |
| 条件分支 | 如果 开关 大门已打开 [0003] 为开启 |
| 场所移动 | 传送至 城镇 [0001]；坐标(3, 4)；下；淡化 |
| 移动路线 | 玩家 的移动路线：3个动作；执行一次；遇阻等待 |
| 等待 | 等待 1秒（原值20，1/20秒） |

示例名称仅说明格式，实际显示原工程中的名称。变量范围显示两端名称和包含中间编号；物品/角色/技能/动画、变量操作数、图片/屏幕、音频和商店都有对应摘要。

本版仅对条件、选项、循环和注释设置少量颜色，缩进有竖线标识；尚未完成全部指令按功能分类配色，用户要求在0.39统一处理。悬停可看完整摘要、原命令编号、位置和原始参数。长列表行截短只影响展示，不截断保存数据。Ruby指令显示“脚本占位”，未支持或格式异常显示“未支持·保留”，不报告可以运行。

移动路线列表同样显示开关名称、混合方式、朝向、图形和音频参数，重复/遇阻选项保持原含义。

## 保存与验收

显示和名称刷新不修改现场，也不触发事件。仍是应用到草稿、显式保存才写入data；保存与备份、冲突检测、撤销/重做沿用0.29。修改定义后重新运行游戏读取。

验收工程位于`../output/0.31/`，从原RM工程重新迁移生成；历史输出保留。打开生成工程的project.godot，进入“魔塔编辑器”；F9打开数据库。可以选择一段原事件，核对条件、开关、变量、传送和路线的名称/摘要，并在系统中改名后检查关联字段刷新。

详细验证见[0.31验证记录](../tests/VERIFICATION_v0.31.md)。
