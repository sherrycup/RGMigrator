# 地图编辑器 · ver0.33

本版合并0.32地图工作区和0.33地图制作工具。打开`../output/0.33/`中生成工程的`project.godot`，进入顶部“魔塔编辑器”。左侧地图列表、中间图块面板、右侧画布同时显示；默认进入绘图下层。

1. 点击“新建地图”，设置名称、宽高、图块集和父地图，确认创建草稿。图块面板顶部可直接更换图块集，沿用原图块编号。
2. 点击“绘图 · 下层/中层/上层”，选择当前要修改的层。在图块面板点击单格或拖动选择矩形笔刷；首格“空”可以清除对应图层。
3. 选择工具，在画布左键绘制。黄色边框表示笔刷或选区，半透明图像表示当前悬停笔刷；地图外边框、玩家起点和事件位置有各自标记。
4. Ctrl+S或“保存”写入文件；未保存数显示在底部。重新打开地图核对，再重新启动游戏读取保存结果。保存前只修改草稿，原输入和运行中的游戏状态不变。

| 工具 / 操作 | 用法 |
| --- | --- |
| 铅笔 B | 单击铺设整个笔刷；拖动补齐经过的格子，一次笔画对应一次撤销 |
| 矩形 R | 按住拖动预览，松开应用；多图块笔刷在矩形内重复排列 |
| 填充 F | 单击填充当前层连通的同图块区域；自动图块按同一素材槽识别，多图块按点击格锚点重复 |
| 橡皮 E | 清空当前层格子，保留其他图层与事件 |
| 选区 S | 拖动框选；Ctrl+C复制当前层完整矩阵，包含空格 |
| 粘贴 V / Ctrl+V | Ctrl+V先在当前格粘贴一次并切到粘贴工具；随后单击/拖动重复铺设剪贴板，地图边缘裁切 |
| 吸管 I / 右键 | 从当前层取样并回到铅笔；图块面板定位所取素材格，自动图块保留当前形状并识别来源槽 |
| Ctrl+Z / Ctrl+Y | 撤销/重做整笔绘制；新建地图也按完整文件组合撤销 |
| Esc | 取消当前尚未结束的笔画或矩形，恢复笔画前草稿 |
| 中键 / 滚轮 | 平移 / 围绕鼠标缩放；顶部−、+、100%、居中提供直接操作，显示当前比例 |

自动图块在绘制、擦除或粘贴后更新周围连接；普通图块保持源编号。地图上不会执行事件或评估实时开关。事件图像以第一事件页作为编辑参考。

点击“事件编辑”切换模式，事件工具和列表显示；双击已有事件编辑，双击空格新建。切换模式不会把事件操作混入图块绘制。地图属性仍由“地图属性”窗口修改；缩小尺寸使事件或玩家起点越界时给出提示。
