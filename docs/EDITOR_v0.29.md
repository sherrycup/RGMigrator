# 数据库与公共事件编辑器 · ver0.29

0.28于2026-10-09经用户抽样验收通过。0.29在生成工程的Godot编辑器中增加数据库窗口，不需要运行游戏。打开验收工程的project.godot，进入“魔塔编辑器”，点击“数据库 / 公共事件”或按F9。

## 数据库操作

顶部选择角色、职业、特技、物品、武器、防具、敌人、状态、动画、图块集、公共事件、系统。左侧按ID或名称搜索，右侧双击字段编辑。引用字段可从原工程名称中选择，素材字段按分类选择；左下显示该条目的图标、行走图或图像预览。

- 普通数值、文本、布尔、音频和嵌套定义保留原字段；不需要手写JSON。
- 角色“各等级能力值”打开六列成长表，行号就是等级；等级0保留。初始/最高等级和经验曲线参数也可修改。
- 职业武器/防具许可、物品/特技/装备/状态的属性与状态集合打开多选窗口。初始队伍可按上移/下移调整顺序。
- 职业“习得特技”、动画“帧”和“音效与闪光时序”等列表可以新增、复制默认结构、删除和排序。动画帧数、单元数按列表/表格自动同步。
- 动画帧“帧单元”打开单元×8参数表，含图案、X/Y、缩放、旋转、镜像、透明度和混合。图案-1隐藏单元；图案0表示动画图像第一格。当前使用表格制作，不提供RM的拖拽动画画布。
- 图块集可选七个自动图块、全景/雾及对应参数。点“图块标记（点图）”在原图像上选择图块，设置四方向通行、全通/全禁、草丛、柜台、优先级和地形；自动图块可统一修改48种连接形状，新图像需要的表格长度自动补齐。也可双击通行/优先级/地形打开编号表。通行位1/2/4/8分别禁止下/左/右/上，15全禁，64草丛，128柜台，按位相加。三张标记表的长度须一致。
- 系统可修改初始队伍、起点、窗口皮肤、标题/结束图、音频、界面用语、开关/变量/属性名称。名称数组可追加；删除和重排被禁用，编号0受保护。

“新增条目”追加新的ID；“复制条目”复制全部原字段并分配新ID；“清空条目”恢复空白默认定义，仍保留原ID。已有条目不会因清空而移位，原事件的引用仍指向该编号。独立测试定义占用的编号会跳过，避免覆盖测试层。

## 公共事件

选“公共事件”，左侧列出原RM的定义，右侧上方是名称、触发方式和开关，下方是事件指令。

| 触发方式 | 用法 |
| --- | --- |
| 无 | 由117、物品或特技调用。例如物品的“公共事件ID”选中此条目，使用后预约执行。 |
| 自动执行 | 指定开关ON时占用前台自动执行。通常在末尾把该开关关闭，避免一直循环。 |
| 并行处理 | 指定开关ON时独立执行。可用等待、条件、循环等控制频率。 |

指令添加/编辑/删除、复制/粘贴、上下移动与地图事件共用组件。条件、循环和选项按完整块操作，选项改名保留分支内容；209打开专用移动路线，公共事件中的“本事件”沿用实际调用者上下文。独立自动/并行公共事件没有来源地图事件，不凭空生成一个。

原Ruby脚本和脚本条件保留为注释占位，未知字段和原代码不丢失。编辑器不会执行这些代码，也不会运行自动/并行事件。

## 草稿与保存

切换条目或类别时，当前合法编辑自动应用到共享草稿。也可点“应用条目”或“应用并关闭”。有错误时会提示并留在当前条目；不写入磁盘。

Ctrl+S或“保存”先应用当前条目，再将地图、事件、数据库和系统的所有草稿一起验证保存。保存前备份到`.godot/rgm_editor/backups/`；如果文件被外部修改，会阻止覆盖。关闭数据库窗口只放弃当前尚未应用的字段；先前应用的其他条目仍留在草稿里。撤销/重做统一管理，重新载入会放弃全部未保存草稿。

保存后重新运行游戏读取新定义。已经运行的游戏不热更新数据库；数据库和地图指纹参与存档校验，修改定义后可能需要新游戏。

原生Troops及其战斗页仅保留查看。工程重载的`$game_troop`、CommonEvent等扩展数据库文件仍完整迁移保留，不删除；自定义Ruby行为和魔塔结算待后续接入。可以编辑敌人定义及其数值，属于战斗的字段只是保留元数据，不因此增加回合制战斗。

地图编辑操作继续见[0.28说明](EDITOR_v0.28.md)。本版本没有新增演示场景，文本窗口增强继续暂缓。
