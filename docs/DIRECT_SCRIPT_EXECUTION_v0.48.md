# 0.48 脚本直接执行试验

2026-10-15，按用户明确要求，闪翼脚本改为直接操作正式状态，取消脚本执行前的大范围状态副本、执行后的全量对象图校验、集中数据提交与出错回滚。原 RM 只读，历史输出保留。新正式输出目录为 `../output/0.48/fix-direct-script/黎之闪翼（开发中）_Godot`。

生成 GDScript 的 `begin/finish` 接口保留，用于设置调用来源、清理本次调用字段、传递等待/公共事件/页面请求和通知显示层。闪翼路径不再创建事务快照，不再运行 `SaveGraph.reason`、全量变量比较、引用重绑或 `RuntimeState.commit_script_data`。直接连接变量、全局/常量、临时字段、自定义记录、角色、队伍、物品和金币；角色读取返回正式实例。人物/图块/跟随/画面/键盘操作在调用后应用，前面的修改在后续语句出错时保留。

公共事件1的扣血、存活条件、奖励以及公共事件23的临时标记现在都使用直接路径。原事件的等待、条件、伤害公式和角色/物品接口的数值规则保持。生成文件的加载与绑定错误仍须报告，不能把未转换代码当成功执行；运行时不再使用只读事务效果证明。存读档和事件前撤回快照仍保留独立的捕获/验证及后台写入边界，其耗时不属于本次取消的脚本事务。

语义错误、绑定/加载失败和 Godot 原生 GDScript 错误统一停止游戏。RuntimeState 注册 Godot 4.5 起提供的 Logger（[官方接口](https://docs.godotengine.org/en/4.5/classes/class_logger.html)），接收引擎脚本错误。首个错误立即暂停游戏并阻止后续脚本入口，弹窗显示地图/事件/公共事件/指令及可用源码位置；确认或关闭弹窗以退出码1结束。无界面测试进程直接输出错误并退出1。不会恢复执行、自动重试失败脚本或回滚之前的修改。操作系统级崩溃或外部强制终止无法保证弹窗。

回归中的旧“报错后回滚并继续”断言已按新授权调整。错误本身由独立进程检查，以免主动退出中断正常玩法回归。覆盖正式状态即时可见、跨根共享/循环身份、角色/背包/金币即时修改、无全量结果检查、语义及引擎错误弹窗、首错保留、确认/取消退出。

性能使用同一台机器、同一个完整 Map010 七事件探针，在私有夹具中关闭 VSync、使用 Dummy 音频、保留正式工程显示设置。先运行旧版，再运行新版本；不得把一次较好的结果称为全地图稳定60帧。最终记录见 `tests/VERIFICATION_v0.48_DIRECT.json`。
