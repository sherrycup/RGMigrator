# 0.57 功能窗口恢复

0.56已获用户验收通过。新分辨率下部分窗口位置按用户安排留待后续统一UI调整；本版恢复功能页的原窗口组成、素材、文字与操作，不把窗口位置调整当作阻断。

正式来源为原Scripts.rxdata按加载顺序导出的有效脚本，不使用独立镜像中另一套覆盖顺序。原RM、素材与已验收0.56归档保持只读。

代码中每组View只读取对应页面的选择和展示快照；控制器持有输入、实际操作与生命周期。FlashPageSurface复用各区节点、原17层面板、FrameM四角光标、文字和带色相人物图。父菜单给出八帧进退；区域切换和光标各自推进，取父/区域最小进度而非叠加位移；方向键在独立光标八帧移动期间被消费，确认/取消仍分别路由。文字与光标在各自区域裁切，页面刷新不销毁整页。深色窗口默认白字，显式富文本颜色/字体仍采用原控制码；静态说明不会触发Message等待、音效或事件。

灵视详情按原208逻辑帧自动轮播，文字16帧淡出/换页/淡入；选中技能后Q/E浏览长说明。原0235在手动Q/E后将计数每帧重置120，实际不会按注释自动恢复；本版保留手动停止、切换敌人重启这一实际边界。BUFF聚焦无原实现的筛选业务；魔法分类、原空装备/成就/合成分支、空的Window_BlasticTitle及回响硬编码“减少0%”均不补造效果。原缺素材、原未完成和既有排除继续记录，Flash前缀仍暂留至收尾。

原公式、直接执行脚本与首错退出规则保持。物品恢复、技能装配、回路装卸、商店交易和选择结果均读写同一RuntimeState；UI预览不安装状态副本。每个.gd文件头和接口索引说明调用方式、参数、返回和归属。

内部检查覆盖真实地图菜单与Viewport键盘、使用/预设、技能配置与角色切换、结晶预览和确认、锁定笔记、灵视聚焦/详情/行动、地图预览、独立装备/楼层、商店买卖数量与返回。图形证据与旧档兼容结果见[验证记录](../tests/VERIFICATION_v0.57.md)。没有原RGSS运行截图逐像素对照，完整剧情通关另行记录。
