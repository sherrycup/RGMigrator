# 0.58 读档与共享物品栏修正

2026-10-19按用户反馈实施，版本保持0.58。正式修正版从只读原RM重新迁移到`../../output/0.58/load-release/`；当前交付以归档索引为准。

读档原来在确认按键里同步校验对象图、角色、事件和资源，并编译/预热运行脚本。地图内读档还把事件先恢复到即将销毁的旧地图，随后才创建新地图，产生重复开销并提前消耗待恢复现场。本轮保留完整校验，使用动态进度、ResourceLoader后台预载只读资源、主线程分帧准备；正式状态只在校验成功后安装，事件现场由新地图恢复一次。失败关闭进度、恢复原暂停与两个提交保护；关闭的进度节点立即释放输入，不等待延迟销毁。

第一次准备资源仍有加载时间，不承诺所有读档瞬间完成或每帧16毫秒。实际耗时和最大帧间隔见本轮验证；资源预载不运行Ruby、不在工作线程访问或安装游戏节点/状态，不依赖档案预览缓存跳过校验。

已只读诊断本机存档副本：Map023，其`audio.playing/memory/fades`均为空；此前读档又无条件跳过地图自动音乐，导致无声。现在旧空记录补播地图自动BGM/BGS；已有保存曲目和播放位置优先。音频快照新增可选`stopped`布尔表，明确停止或淡出结束保持静音，旧三字段音频快照仍可读。无法从旧空记录区分历史的有意停止，这类旧记录统一按地图自动播放；新记录能保留该意图。音量设置及用户静音偏好不覆盖，原存档文件不改写。

地图右侧与物品页预设现在是同一个`FlashPlayerHUD.item_canvas`及同一帧纹理、数据与八帧光标。物品页不再创建`presets`绘图区域；显示位置、格框、数量和1—9编号沿用地图栏，预设编辑只切换选择状态。恢复目标页收起同一栏；回地图继续使用原控件。它只绘制一次，物品编辑时临时提到菜单图形之上；正常地图保持第9层，仍被Message第20层遮挡，不创建第二个窗口。

新增`SaveLoadProgress.read_slot(slot,host)`：await取得完整校验结果，成功由持有方调用`RuntimeState.restore_prepared(prepared,false,false)`并切换预载场景，再调用`finish_after_scene()`；失败`close()`。`restore_live_events=false`只将事件现场留给新Game；既有在当前地图恢复的调用默认true。`SaveService.read_slot_cooperatively`复用规范SavePreparation；同步读取同样每次核对当前文件，JSON解析出的图由读者独立持有。

自查及截图见[本轮验证](../tests/VERIFICATION_v0.58_LOAD.md)。此前UI修正及完整0.58记录是历史证据，本轮不冒称所有历史测试重新执行。
