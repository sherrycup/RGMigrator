# ver0.37 数据库与复杂数据

打开新工程的project.godot，进入“魔塔编辑器”，按F9或点“数据库 / 公共事件”。选择数据库与条目后，按用途切换右侧页签；名称、数值、选项、开关直接编辑，引用统一显示[0003] 名称并可搜索。常用属性专用界面替换原字段/值表，图片预览置于基础页，双击更换素材。原工程实际额外字段放在“自定义兼容字段…”，说明其保留用途，没有额外字段则隐藏。系统的原生战斗图色相归入基础设置。

## 成长、习得与集合

角色“成长”页点击编辑能力，表格以等级为行，最大HP/SP、力量、灵巧、速度、魔力为列，双击整数修改，选中格显示所属等级和能力。等级0为RM保留数据。职业“习得特技”页选择条目后设置等级，点特技按钮按名称或编号选择；支持新增、删除、上下移动，同等级多项不合并，原条目额外字段保留。

装备允许集合、属性集合及状态集合按名称勾选，窗口显示选中数量。初始队伍集合可调整顺序。属性与状态有效度按具名条目选择A–F，对应原生1–6；原工程范围外值明确显示“原值”，浏览不更改。

## 名称管理

“系统”从左侧进入基础与图像、玩家起点、界面用语、音乐与音效、开关名称、变量名称、属性名称。搜索编号或名称，选择条目直接改名；每页100项。新增只追加末尾，编号0保留，清空名称不会删除编号。应用条目后共享引用会刷新，保存后下次打开仍使用原编号。

## 动画

动画基础页设置名称、素材、色相和显示位置；“动画编辑”页提供帧列表、图案预览、单元列表及八项参数。图案从0开始，-1为隐藏；坐标单位为像素，缩放为百分比，旋转为度，不透明度为0…255。192px图案按五列取图，画布显示单元的缩放、旋转、镜像、色相和混合方式。帧支持追加、复制、删除，每帧最多16个活动单元。

“播放预览”默认20动画帧/秒，可调整预览速度；从首帧播放一次，到末帧停止；“循环播放”默认关闭，可主动开启。按时序播放SE，各自使用音量与声调，“模拟命中”筛选命中/未命中条件。关闭停止声音，不启动游戏；目标闪光仍以正式运行时为准。“音效与闪光时序”页设置作用帧、音效名称/音量/音调、闪光范围/颜色/持续帧和条件。界面帧号从1开始，保存仍为原RM的0起始编号。有时序的帧须先移动或删除时序才能删除；删除前面的帧会同步后面的时序。

## 地图位置与事件

事件模式下左键拖动事件到另一格，松开提交一次移动，Esc取消。事件ID、页与指令保持。右键目标格选择“设置玩家起点”，标记立即更新；工具栏原按钮删除。

系统“玩家起点”及事件“场所移动”的直接指定方式都加载实际地图图块与事件图形，左侧选择工程实际存在的地图，左键点格；滚轮缩放，中键平移，“适应地图”恢复全图视野。系统点击只改变条目草稿，应用与保存后生效；场所移动保留朝向与淡化。变量方式仍选择具名地图/X/Y变量，不猜运行时变量。

事件、公共事件和路线采用“类型 名字 变化”，例如“开关 [0003] 3号开关 打开”、“物品 [0001] 回复药 +2”，简单数量写成“金钱 +10”。具名引用统一把编号放在名称之前。

## 音频素材与试听

数据库新增“音频素材”，左侧选择BGM、BGS、ME、SE，搜索或双击试听。所有音频选择入口共用试听窗口，包括系统、地图自动音乐、事件声音、移动路线SE、菜单使用音效与动画时序。音量0…100%、声调50…150%用滑块或整数框调节，播放中立即生效；确认写回引用与参数，取消保留原数据。试听及关闭不会改写原文件；音频属于编辑器，不改变游戏音频状态。缺失、未导入或不支持的文件明确提示无法试听。

## 应用与保存

编辑只修改独立草稿。切换条目自动应用当前条目，或点击“应用条目”；Ctrl+S显式写入文件。关闭会放弃当前未应用条目，已应用草稿仍可保存或撤销。保存后重新运行游戏读取定义；原生Troops与战斗功能边界保持。

图块属性画布已随本版放大到1.5倍，每格显示48px，实际素材和图块尺寸仍为32px。多素材组合、逐格属性及扩展图层沿用[0.36操作](EDITOR_v0.36.md)。事件图形入口沿用此前交互，完整指令配色仍安排在0.39。
