# 0.43：事件脚本入口

按原0.4计划完成本阶段入口接入。2026-10-11用户决定在脚本功能移植完成后进行整体验收；本版执行内部验证和正式迁移，不另加演示场景。游戏玩法、数据对象、画面生命周期、自定义持久化和源码工作区继续按0.44—0.49推进。

## 执行链与源码位置

迁移器 `ScriptMigrationInventory` 保留原始地图/公共事件记录，解析和编译后由 `ScriptEventIntegrator` 写入绑定；`EditorScriptAdapter` 恢复已生成的355/655和111条件，未转换的条件保留整个原分支。路线保留全部原步骤，45是否可运行由整条路线预检决定，不能删掉脚本后执行剩余动作。

生成工程调用链：

```text
EventScheduler → EventInterpreter (355/655、111)
MapCharacter → CharacterRoute (45)
                    ↓
ScriptRuntime.validate_binding → execute_bound
                    ↓
runtime/generated/<unit_id>.gd 的 program / ruby_method_*
                    ↓
ScriptSemantics → RuntimeState 原生开关、整数变量、金币
```

自定义库仍位于 `runtime/generated/script_<序号>.gd`。事件入口位于 `runtime/generated/event_<序号>.gd`；二律背反的相邻355尾部重试另有 `_retry.gd`。原脚本ID、加载顺序、类/方法/原行号到生成函数及行号的对应关系，继续使用 `script_inventory.md`、`data/script_units.json`、`data/script_semantics.json` 和 `data/script_source_map.json`。

库按需要加载完整、已转换且仅包含声明的单元，保持加载顺序和alias捕获版本。父类或后续覆盖未转换、初始化含游戏副作用、定义循环时明确失败，不跳过未转换的新版本去运行旧实现。此机制不等于已经接管原工程Main或全局初始化。

公共事件来源保留数据库文件名。二律背反同时包含 `CommonEvent.rxdata` 和 `CommonEvents.rxdata`，相同事件ID和指令位置不能合并；绑定、AST、IR和源映射均区分来源，原生公共事件调度读取实际 `CommonEvents`。两份数据完整保留。

## 返回、上下文与恢复

- 原Ruby不执行；运行时只加载生成的GDScript。绑定核对原文SHA-256，源码改变或文件缺失时先失败，不能继续发奖。
- 111采用Ruby真值：只有false和nil是假；0、空字符串、空数组为真。失败不会选择任一分支。
- 按两份原Interpreter实现合并355/655。闪翼忽略false；二律背反false让出一次更新，并从最后源记录恢复：最后为655则进入下一指令，最后为355则只重试该尾部。单条355的false仍按原行为逐次重试。
- 事件可读取实际 `@event_id`、`@map_id`、原源记录的 `@index`；公共调用隔离实例字段，继承有效调用者事件，传送后新子调用使用当前地图，诊断保留原来源和调用链。原生现场字段未适配的读写给出错误，不伪造值。
- `@wait_count` 按原工程默认帧率转成秒，通过原生等待器推进。闪翼默认60、二律背反默认50；可变帧率配置的完整系统接入留到后续阶段。原生106/路线15仍按已有1/20秒契约。
- 路线45使用实际人物上下文，false返回不会阻止路线推进；脚本等待后从下一动作继续。强制和自主路线共用入口。
- 执行失败回滚本次状态写入及定义加载，记录源码行列和事件位置，发出failed/main_aborted，释放人物锁，不发出成功completed。
- 原生现场存档保存已消费的指令位置、等待时间、实例字段和公共调用栈，恢复不会重新发奖。自定义全局/集合常量、对象、共享引用或循环的完整持久化按0.47实现，本版明确拒绝相关存档，避免丢失状态。

## 如何阅读本版状态

`generated` 表示当前语义可生成文件；`event_integrated` 表示绑定出现在实际事件或路线数据中；`runtime_verified` 仍不自动设为true。即使入口已绑定，它所调用的角色、物品、战斗、窗口等依赖仍可能尚未移植。实际功能是否可运行以运行验证及后续阶段为准。

编辑器显示已绑定单元ID，保留条件分支和路线。已绑定355按原分组整体选择、复制、删除和移动，包含相邻355及尾部重试记录；当前不直接改写，源码工作区和重新编译按0.48接入。条件或路线原文改变后旧绑定会失效。
