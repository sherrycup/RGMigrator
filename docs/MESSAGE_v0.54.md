# 0.54 Message 对话气泡

本版补全地图 Message 的显示和交互。普通文章、合并选择项、数值输入继续使用同一解释器、EventUIBroker 和 RuntimeState.flash_messages；没有第二套变量、角色或奖励执行器。

## 实际来源

正式输入是 `../rm_template/魔塔样板7630·改/Data/Scripts.rxdata`，按加载顺序展开并应用已登记修正后，对照0149—0157 Message、0161事件文章、0191控制器和历史窗口的实际入口。独立展开的 `Scripts/` 镜像含另一套时钟修改，不作为覆盖正式数据的依据。正式0150设置 `AUTHORING_FRAME_RATE=40`，W/T/ML/MU仍换算到60Hz运行时；本版没有更改原等待时长。

原素材 `Graphics/Windowskins/MessageBox_Frame.png` 的32×32边框、右侧16×12上/下箭头、白色230透明度内底继续使用；名字为24号楷体及四层红色渐隐下划线，头像为96×96、每行四格。

## 本版行为

- 气泡围绕玩家或 `\p[id]` 事件人物的画布坐标更新；`\p[x,y]` 使用固定坐标。普通模式限制完整边框、箭头在可用区域，左侧HUD保留224像素；模式3按原允许移出屏幕。
- 名字参与宽度测量；头像分组检查完整96×96范围，缺图和越界在加入活动气泡及历史前明确拒绝。
- 长文按实际字体度量自动换行，按视口可用像素高度分页。下一页的第一条词元绘制前暂停，确认后按原2像素/逻辑帧滚动，末页确认关闭后才返回事件；滚动期间确认不会提前关闭。并行提示自动滚页，不阻塞地图。
- `\!` 暂停、`\|` 显式滚页、`\.` 唤醒解释器、打字开关、等待/自动关闭、位移、颜色/透明度、字体/字号/粗斜体、图标、行间距/对齐、合行及姓名头像控制码沿用原入口。纵横位移连续切换时清除上一轴方向，避免下一段移动继续偏移另一轴。
- 每个选择项绑定原始行号范围，自动换行后光标覆盖该分支的全部显示行；上下选择同步滚动，取消返回原分支编号。输入只在正文结束后启用。
- 数值输入保留独立32像素区域。左右选择十进制位，上下在该位0—9循环；键盘数字及退格仍可直接输入。确认结果由原解释器写入目标变量。
- 历史窗口保留剧情/主动信息两个频道、原始记录及容量；显示侧保留颜色、字体样式和图标，去掉计时/声音等演出效果，不重新执行事件。

## 调用与保存

`FlashMessageController.present(payload,request_id,event_id,hint)` 创建气泡，`FlashMessageOverlay` 是唯一60Hz推进及显示节点。`FlashMessageLayout` 负责几何和按源行范围生成选项矩形，`FlashMessageView` 只读取绘制。窗口尺寸变化时 `relayout(next_size)` 重排同一词元和选择，不重新记录历史。

`FlashPresentationState` 增加可选 `message_ui`，保存原始词元、待翻页下标、翻页恢复状态、当前页及数字光标；读取旧0.53数据时使用缺省值。新增数据在安装前验证词元与已验证执行序列一致、游标范围和暂停状态一致；不能借可选字段跳过既有存档校验。恢复绑定沿用原请求编号映射，不重跑已经执行的奖励。

执行取消、新游戏、换图和读档仍由原执行代次/场景重置清理气泡。原生await保存限制及首错停止行为保持。
