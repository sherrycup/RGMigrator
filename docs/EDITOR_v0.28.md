# ver0.28 地图与地图事件编辑器

0.28目标：在Godot编辑器中打开原地图与原事件，修改、制作并保存，供正式运行时验收。0.29再实现数据库和公共事件编辑；Ruby转换暂缓。用户排除的是RM原生回合制战斗，闪翼/样板重载的Game_Troop按实际用途后续接入，不按类名排除数据。

## 使用

迁移后用Godot打开生成工程的project.godot，会默认启用addons/rgm_editor/plugin.cfg，显示“魔塔编辑器”主页面。旧的用户验收输出不会自动覆盖，需要重新迁移到新目录获得编辑器。

最新反馈修复输出位于仓库父目录output/0.28/fix-01/，由当前迁移器从rm_template/重新迁移两份原工程生成，打开各自project.godot即可。原output/0.28下的验收工程保留。首次素材导入需要等待完成。[验证记录](../tests/VERIFICATION_v0.28.md)列出原工程覆盖与回归结果。

- 地图树选择原地图；“图块”标签选择刷子。三层图块独立绘制，事件层显示事件编号。
- 铅笔、矩形、填充、橡皮及区域选择/复制粘贴可制作地图。右键图块吸取刷子；自动图块按同种邻接连接。中键拖动、滚轮缩放。
- 地图属性调整名称、尺寸、图块集、父地图与BGM/BGS；新建/复制地图维护地图列表和层级。缩图导致事件或玩家起点越界时拒绝提交。
- 事件层双击已有事件编辑，双击空格新建。右键提供复制、粘贴、删除、移动到此处和设置玩家起点；事件复制使用新ID。
- 事件窗口提供名称、坐标、新建/复制/删除/排序事件页。页配置包括开关/变量/独立开关条件、图形、自主路线、速度频度、动画/穿透/朝向/置顶与五类触发。满足条件时运行时使用编号最大的页。
- 指令列表显示缩进、原编号和支持状态。添加/编辑打开中文字段表单，双击字段填写值；数据库/素材可按名称选择。指令块可复制、粘贴、删除、上下移动；条件、循环、选择自动生成配套标记。改变选项保留已有分支，不能直接删除仍有内容的选项分支。
- 209“设置移动路线”打开专用面板：先选择玩家、本事件或地图中的指定事件，再用“移动／朝向／属性与音效”按钮插入动作。左侧动作列表支持双击编辑参数、复制、删除与上下排序，重复执行和遇阻跳过可勾选；末尾结束标记保留。事件页的“自主移动路线”字段双击后打开相同路线编辑窗口。
- 左侧“事件页属性／编辑字段”只操作选中的属性。列表增删排序按钮仅在选中可编辑列表时显示，80项翻页按钮仅对长列表显示；右侧“添加／编辑／删除”等操作事件指令。
- 自主路线在“自主移动方式＝自定义路线”时执行；209强制移动路线可以操作自主移动方式为固定的事件。
- “应用事件”提交地图草稿；保存或Ctrl+S写入data。撤销/重做作用于草稿，地图创建的多文件操作作为一个操作。Godot保存和运行前检查会调用同一保存接口。

编辑界面没有运行地图调度，不推进自动/并行事件。运行游戏时读取已保存的数据，调用公共事件可选择现有ID；0.28没有数据库或公共事件修改界面。底层绘制工具为单图块刷子，自动图块提供原生48种图样的邻接连接；地图区域复制可形成多图块印章。当前没有地图删除入口，也没有原生回合制遇敌设置。

## 脚本占位与数据保存

地图355/655在迁移时转换为注释，占位注释的_editor_original保存原指令和参数。脚本条件111/type12保留完整原条件分支作为注释，不猜真假；该分支等待后续Ruby转换恢复。路线45保留原路线后移除脚本执行入口，并加注释说明。非脚本字段、未知工程字段、ID和嵌套内容保留；当前运行时不能执行的其他指令仍显示保留状态。公共事件脚本同样转换为保留原数据的注释，让地图公共事件调用可使用非脚本内容；其编辑界面在0.29实现。

保存先检查整个批次和外部文件版本，写入暂存文件后统一替换；替换失败恢复原文件。保存前副本位于.godot/rgm_editor/backups/。编辑器外修改同一文件时阻止覆盖，重新载入前请保留自己的改动。修改地图/系统定义可能导致已有存档数据指纹不一致，验收时使用新游戏。

## 验证入口

Run-Headless.ps1的两份样例各增加EditorCompileTests和EditorTests，检查原地图/页读取、脚本保留、三层寻址/自动图块、事件与页表单、选项分支保留、文件事务/外部冲突，以及保存后的数据交给正式解释器执行。Run-EditorRender.ps1实际启动Godot编辑器插件，检查游戏未运行，并保存地图、事件页、路线表单画面。
