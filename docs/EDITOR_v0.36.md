# ver0.36 多素材图块集、图层与地图管理

在 Godot 打开新生成工程的 `project.godot`，进入顶部“魔塔编辑器”。地图引用数据库中的图块集，多个地图可以共用同一套素材和属性。

## 组合普通图块素材

1. 在地图图块面板点击“编辑当前图块集…”，或按 F9 → 图块（图块集）选择条目。
2. 点击首页的“普通图块素材…”，用“追加素材…”选择已有素材。普通图块规格为宽256像素、高为32像素的倍数；自动图块仍使用独立的7个槽位。
3. 列表按顺序排列，第二张接在第一张下方。右侧预览同一套排列，各段显示名称、行数及编号范围。使用原图片，不生成合成大图、不补边或缩放。
4. 可以替换、上下移动、移除素材。尾部追加保留原编号；换序或替换图片高度改变后，同步所有共用地图的图块、事件图形和属性。仍被使用的素材或行不能移除。
5. “应用组合及当前条目”把本条目的字段及编号同步一起应用到编辑草稿，单次撤销可以恢复；Ctrl+S才写文件。取消组合窗口保留原草稿。单素材和多素材统一从“普通图块素材…”管理。

编号布局变化或更换图块集后会清空旧编号笔刷及图块/事件剪贴板，请重新选择或复制。

编号同步覆盖地图和数据库定义，编辑器不会改写已有游戏存档中的事件运行现场。素材换序后的运行验收请从新游戏开始，避免旧存档恢复先前的图块外观编号。

同一张图片可以重复加载，各段有独立身份与属性；总编号上限32767。组合增加少量配置和属性数据，原素材只保存一份。外部改变图片高度不会自动移动后续编号，会提示重新选择素材；通过组合窗口替换后再同步。仅修改源PNG内容不会由编辑器自动转移属性含义。

## 逐格标记

数据库图块首页直接显示常驻图块画布，右侧精确编辑所选格的属性；原“字段 / 值”占位表和二次属性弹窗已替换。顶部选择属性模式，每格直接显示标记，点格修改，拖动连续涂改。六种属性及“自动图块与背景”页签复用同一张画布，切换模式保留滚动位置。地形数字按整数显示为0…7。一次拖动使用起始格选出的值，并补齐快速拖动经过的格子。

| 模式 | 标记与操作 |
| --- | --- |
| 通行 | ○通行、×禁止、△部分方向；点击在全部通行/全部禁止之间切换 |
| 方向通行 | 四个箭头显示允许/禁止；用右侧四方向设置选择笔刷，再涂到其它格 |
| 优先级 | ★0…5，点击循环；0为地面，其它值参与人物脚点前景排序 |
| 草丛 | “草”表示人物下半身半透明，点击切换 |
| 柜台 | “柜”允许隔格对话，点击切换 |
| 地形 | 0…7，点击循环，也可在右侧精确输入 |

右侧可按图块ID精确设置全部属性。自动图块勾选“48种形状共用设置”时整组更新。图块集名称在首页直接编辑；右侧“自动图块与背景”提供7个自动图块槽位、全景、雾和战斗背景图片，双击更换。背景参数使用独立具名控件。应用条目后保存，关闭丢弃当前未应用修改。通行设置保留其它原生/扩展位。

## 图层与事件

旧RM地图及新地图默认三层。点击“增加图块层”追加空层，上限32层；第四层开始也是图块绘制，事件编辑使用独立按钮。地图属性可以改层数和各层名称，减少层数前必须先清空要移除的层。

铅笔、矩形、填充、橡皮、多图块笔刷、复制粘贴与尺寸调整处理当前地图实际层数。每层的“显示（仅编辑器）”复选框用于查看其它层，隐藏的当前层不能绘制；保存后的游戏仍显示全部层。额外层继续使用图块数据库的原有通行与优先级规则，名称“装饰”不会自动使其无碰撞。

事件的“当前地图图块…”选择器包含全部普通素材，预览和运行时图形使用同一个编号映射。事件行走图双击及下方两个按钮沿用0.35交互，后续再考虑统一入口。完整事件指令配色仍在0.39。

## 地图管理

新建、复制和地图属性修改作为一次草稿操作撤销。复制保留所有图层、事件和扩展数据；尺寸调整保留各层对应坐标。缩图不能截掉事件或当前玩家起点，请先移动它们。父地图须存在，不能选择自身或形成循环。

事件模式选择格子后点击“设置玩家起点”。地图、系统起点、图块集及元数据仍通过统一Ctrl+S显式保存；外部冲突会阻止覆盖。修改后重新运行游戏读取定义。
