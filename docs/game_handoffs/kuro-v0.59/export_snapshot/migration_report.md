## ver0.59 标准功能与限制
已提供 Godot 标准主菜单、队伍摘要、角色状态及返回标题/退出。地图空闲时按 Esc/X 打开，保留窗口皮肤与界面用语；属性标签统一为标准力量/灵巧/速度/魔力/攻击力/物理防御/魔法防御，不沿用 Ruby 自定义属性映射。皮肤缺失时使用简易样式并报告。
生成工程内置ver0.59地图、事件、数据库与公共事件编辑器。Godot的“魔塔编辑器”按F9打开数据库；引用显示名称＋编号并支持搜索，事件和路线使用中文摘要。角色成长、装备许可、图块标记和动画单元可用表格/集合制作，公共事件提供无/自动/并行及共享非脚本指令编辑。草稿通过显式保存写入data，保留原ID和Ruby注释数据。原生Troops只保留查看，扩展数据库文件仍迁移保留。
通用页面使用标准运行时；已识别项目的自定义属性、货币与玩法由上述项目适配提供。具体覆盖以方法对应和行为验证为准。
