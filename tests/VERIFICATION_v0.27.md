# ver0.27 验证记录

日期：2026-10-08。引擎：Godot 4.7.2 标准版、Compatibility，Windows。仅修改仓库和隔离导出工程；rm_template及用户已验收输出保持只读。

## 实现范围

- 352调用实际存档页；成功保存和取消均关闭页面并只恢复原调用者。保存快照将已打开的menu/save等待归一为关闭后的续行，读档不会重复弹出页面或重新发放之前的奖励。
- 134禁止普通玩家存档，原生352显式调用可越过禁止标志，存档仍保留该标志；传送、瞬时截图/过渡、场景终止、玩家半格及独立验收地图仍不能保存。
- 当前地图所有事件按地图ID/事件ID记录位置，包括无活动页和已删除事件。活动/隐藏人物保存朝向、速度、图形/色相、原方向/图案、透明/穿透/固定方向/步行及踏步动画、透明度、混合、频度和置顶。移动路线完成后这些属性不会从快照中清除。
- 保存平滑运动cell/target/start、运动类型与时间进度、动画计时；自主/强制路线、游标、等待、原路线与原游标、故障状态都恢复。读档后完成剩余强制路线，再回到原自主路线。
- 前台、地图并行和公共并行分别保存指针、调用栈、循环、分支和剩余等待；保存调度故障及轮转游标。JSON数字归一化，避免整数键或原生命令数字在读档后失配。
- 待显示的文章、选项、数字、按键、商店、姓名、菜单和存档请求保留原payload与所属执行者。读档重新创建请求ID和wait token；旧回调不能重复恢复或发奖励。
- 菜单物品/技能接通一次性公共事件预约。先校验引用、菜单使用资格、目标、状态限制及库存/SP，再预约和消耗，退出菜单后执行。单体技能选人时不扣SP；确认后才扣。已有确定性恢复物品继续有效，未知队友结算、复活/状态/随机效果不部分执行。
- 预约尚未执行时也可存档；读档执行预约不会再次扣物品/SP。公共事件优先于自动事件启动，正在运行的前台仍按原生先完成。
- schema1新增可选event_state/common_event_reservation，旧迁移器存档缺字段用默认；不读取RM旧存档。普通离开再进入地图仍按源定义重建，临时删除只在当前地图实例保留。
- RuntimeState.restore_prepared可在已有Game里立即恢复现场，也支持标题读档后新建Game时一次性恢复。校验脱离现场完成，坏坐标/路线/执行栈/队列/公共事件引用不部分修改状态。

没有新增演示场景，测试夹具只用于专项回归。文本增强、Ruby和原生回合制战斗没有接入，魔塔自定义结算继续暂缓。

## 边界

存档保留当前地图实例的事件现场，不将普通换图改成跨地图永久记忆。玩家行走仍等完整格，NPC半格可恢复；瞬时截图和ME/SE不序列化。技能只接通公共事件使用入口，不宣布所有技能结算效果已经支持。数据指纹或测试定义改变时旧存档仍可能拒绝，原文件和有效备份不被损坏进度覆盖。
