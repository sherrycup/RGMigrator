# ver0.51 中文接口文件头

2026-10-16，按用户要求把单行职责说明扩展为可查阅的中文调用接口和参数说明，版本仍为 ver0.51。

## 实际内容

源仓库 398 个维护中的 `.gd` 文件均有完整文件头，包含职责、调用方式、构造与公开方法签名、逐项参数含义/类型/默认值、返回结果，以及存在的信号、生命周期回调和常量。共登记 2128 个接口（含构造及测试辅助接口）、2728 个参数、132 个信号、175 个生命周期回调。生产脚本为 238 个，公开方法为 1473 个。

签名从实际顶层声明读取；内部辅助方法和内部类方法不作为所属脚本的对外接口。说明位于 `@tool`、`class_name`、`extends` 之前。原来源与实现注释保留。

重点接口另有经实现核对的中文约定，例如：

- `Editor_CommandList.configure`：完整指令数组、文档服务、人物名称表，以及 `draft()` 深复制结果与 `changed(list)` 信号。
- `FlashMessageController.present`：message/choice/number 的 payload 字段、请求编号、事件锚点、提示模式、消耗字段与成功/失败返回。
- `ActorState`、`RuntimeState`：角色与正式状态归属、原编号、属性键、配置顺序和常用修改接口。
- `SaveCodec`、`SavePreparation`、`SaveService`：捕获与完整验证的边界、异步 pulse/graph_check 回调、备份恢复和结果字段。
- `Editor_Documents`、`Editor_ScriptWorkspace`：编辑草稿、工作副本保存、重新转换发布的调用顺序及实际返回。

职责在 `tools/script_descriptions.json`，中文参数及重点约定在 `tools/script_api_docs.json`。`tools/gdscript_interfaces.py` 平衡括号和字符串以提取多行声明与集合默认值；`tools/sync_script_headers.py --check` 比对完整文件头并检查手写说明中的方法和参数仍然存在。布局索引、存档准备规范生成器也使用同一文件头生成方式。

运行时生成程序提供 execute/state/session 与 program/env 的接口说明；技能目录说明 source_skills 的参数、返回结构及 INPUT_SHA；版本和附带编辑器工具同样带详细说明。`Editor_` 前缀保持，`Flash` 按已确认条件暂留。
