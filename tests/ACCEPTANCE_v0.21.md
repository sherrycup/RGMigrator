# ver0.21 人工验收

使用新迁移工程并开启“准备测试物资”。原生回合制战斗不迁移；Ruby依赖仍显示定位诊断。魔塔结算后续单独接入。

1. 在空闲地图按Esc/X → F6 → **正式事件验收地图**，可用方向键确认或鼠标“进入”。原地图暂停；首次自动事件等待1秒，期间不能移动，随后“自动”计数为1且恢复移动。
2. 观察两条地图并行及公共并行计数独立变化。点击“启停公共并行”，公共计数停止/重新开始，地图并行继续。
3. 走到柜台下方，面朝上按Z：显示第一条消息，地图并行继续。点击继续后调用公共事件等待1秒，返回第二条消息并增加确认计数；最后继续恢复输入。按住确认不会立即重触发。
4. 走到左下触碰点(2,7)，确认消息后事件暂时删除，“删除后继续”计数增加。再次走过不重复显示；重新进入验收地图后恢复。
5. 对话结束后按F7或“退出验收地图”，恢复原坐标、变量与原地图实例。原有暂时删除与并行等待保持，验收变量不写回原进度。对话或主事件进行中不退出。
6. 普通菜单/商店暂停地图和事件时间；关闭后继续。仅存在不请求界面的背景并行时，仍能打开菜单。
7. 存档遇到执行中的事件/并行、本地图暂时删除或验收地图会给出明确原因；schema1尚不保存这些现场。离开有暂时删除的地图、关闭并行条件并结束事件后，再在空闲地图保存。
8. 分别以640×480、800×480、768×768检查工具入口、HUD、中文消息和退出按钮。不要把独立“人物与地图”预览的触发提示当作正式命令执行结果。

事件主动碰玩家通过正式MapEvent.move_straight及阻挡接触路径实现，自动测试已验证；页自主移动及移动路线命令在0.23接入，此版验收地图不模拟自主路线。帧率对比、公共自动/嵌套退出、旧回调、换图与长循环由EventTests验证。实际记录见[验证记录](VERIFICATION_v0.21.md)。
