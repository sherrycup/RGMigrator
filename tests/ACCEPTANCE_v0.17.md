# RGMigrator ver0.17 人工验收清单

ver0.16 已获用户验收。ver0.17 补齐图片/屏幕原生底层及测试入口，不新增地图事件指令、不转换 Ruby。事件系统安排在 ver0.2–0.3；ver0.2 前优先图片/屏幕、角色/地图。天气、雾、完整地图表现不属于本次验收。

## 准备与入口

1. 用新版迁移器重新迁移到**新的空目录**，保留“准备测试物资”。不覆盖原已验收工程。
2. Godot 标准版打开输出 project.godot，等待导入；运行 → 新游戏。若原样例启动事件提示未支持指令，先关闭诊断。
3. Esc/X → F6（或菜单底部测试工具）→ 图片与屏幕。640×480 至少检查一次，可另在 800×480、768×768 检查。不同尺寸用于布局/负载，不要求修改原 RM 工程。
4. 上方选择编号 #1 和原 Pictures 素材，点击“显示/替换”。下方显示的是原素材的真实地图叠加；下拉框另有“工具绘制 · 测试色块”，可用于更容易观察的对照，不是 RTP。

## 图片：独立编号与变换

- [ ] “追加双图”：两个位置同时显示，互不覆盖；编号较大绘制在较小编号之上。
- [ ] 编号 #1 点“显示/替换”：仅替换 #1，#2 保留；#1 的旧旋转/色调/过渡重置。
- [ ] “移动/缩放”：在约两秒内平滑移动/缩放，结束停在目标；再次点击从当前状态开始，不跳回旧起点。
- [ ] “透明/混合”：逐次切换加算、减算、正常，同时改变透明度；半透明不等于擦除。
- [ ] “旋转开关”：当前图持续旋转，再按停止；另一编号不跟随旋转。
- [ ] “切换原点”：左上/中心间切换，位置含义改变；“图片色调”只影响当前图。
- [ ] “擦除当前”：当前编号消失，另一图和地图保留；重复擦除不崩溃。可选择 #50 检查编号上限。
- [ ] 关闭界面后行走：图片不随角色/摄像机移动，固定在逻辑屏幕坐标。

预览显示图片时会先按原比例适配下方区域，便于大图片测试；生产接口的缩放仍是明确百分比，不强制适配。鼠标选编号/素材，按钮可以方向键+Enter/Space/Z 或点击，Esc/X 逐级返回。

## 屏幕与界面分层

- [ ] “地图色调”：地图、玩家和地图动画改变色调，图片与上方工具控件不被同一色调污染；再次点击复原。
- [ ] “屏幕闪光”：覆盖地图和图片，工具/菜单/对话不被盖住；约一秒消退，不留下遮罩。
- [ ] “地图震动”：地图水平震动，图片不动，上方控件不动；结束回到原视口，不影响角色逻辑坐标。
- [ ] “全部重置”：所有编号和屏幕效果复原；地图、队伍、金币、背包、开关变量不变。

## 暂停、存档与生命周期

1. 显示双图，开启旋转并点击移动；在测试页能看到效果推进（地图输入仍暂停）。
2. Esc 返回测试工具/主菜单：效果暂停。关闭菜单回地图：继续；位置/朝向和原地图实例保持，不重跑启动事件。
3. 保留图片和旋转 → 主菜单存档 → 返回标题 → 继续游戏读取刚才槽位：图、色调、角度/旋转及未完成过渡恢复，不重复发测试物资。
4. 返回标题：没有图片残留到标题；再次新游戏：没有旧图片、闪光或震动。
5. 修改导出 `data/test_setup.json` 的 enabled 为 false，再次新游戏：不出现测试工具和测试物资，原生图片接口仍可由 GDScript 使用。

原生接口时长为秒、旋转为度/秒，震动为像素振幅/Hz/秒；不是旧 Ruby API。普通存档仍只在空闲地图菜单保存，运行事件和地图动画不保存。旧新格式缺少 screen 字段时默认中性，不保证数据指纹或测试定义改变后仍可读；不读取 RM 旧存档。
