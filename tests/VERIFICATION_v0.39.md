## 5000编号规模的实际交互耗时

| 操作 | 二律背反 / 1280×800 | 黎之闪翼 / 1600×1000 |
| --- | --- | --- |
| 扩容至500 | 44.3 ms | 37.1 ms |
| 扩容至5000 | 50.1 ms | 60.0 ms |
| 跳转编号 | 115.6 ms | 91.8 ms |
| 跨页搜索 | 23.0 ms | 23.0 ms |
| 保存稀疏数据 | 976.5 ms | 185.2 ms |

耗时来自实际Godot编辑器中的隔离稀疏物品与名称数据，包含UI刷新；同时运行的检查及资源导入会影响数值。这些数据不是游戏帧率测试，也不代表每个槽位都有复杂定义时的开销。物品示例保存文件约36.9KB，5000编号中大量槽位为空；首次实际编辑才生成默认结构。缩容保护使用原生字段/集合/事件/路线引用，未知指令中的可能越界数值保守拒绝，Ruby仍按既有契约保留。
