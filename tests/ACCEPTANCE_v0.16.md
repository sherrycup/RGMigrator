# ver0.16 人工验收清单

本版验收角色运行数据与成长，以及上版列表滚动修正。不是恢复魔塔 Ruby 公式、战斗、地图/事件编辑器。ver0.15 已于 2026-10-05 获用户验收；本清单不代表 ver0.16 已获用户验收。

## 准备

1. 运行当前 RGMigrator，确认标题为 ver0.16；保持“准备测试物资”勾选，选择新的空导出目录，不覆盖旧工程。
2. 用 Godot 标准版打开新输出 `project.godot`，待资源导入完成再运行，点击“新游戏”。如果出现原地图的不兼容事件诊断，先正常关闭；不会自动跳过原 Ruby 初始化。
3. 在空闲地图按 Esc/X。点击主菜单底部“测试工具 · F6”或按 F6，看到角色数据与成长、测试商店、状态接口。方向键和 Enter/Space/Z 可进入，Esc/X 逐级返回。

## 角色属性

1. 进入“角色数据与成长”，默认选择 atk。记录数据库、装备、base、永久修正及最终值，点击“永久修正 ＋1”，永久修正应增加 1，未到上限时最终值增加 1。
2. 选择力量 str 或其他属性（下拉框或 Q/E），检查同样的来源变化。样例部分基础值已是 999，上限时最终值不再增加不属于错误；先 −10，再 +1 可观察变化。
3. 逐级返回主菜单 → 装备，换上/卸下测试剑；再看状态和角色工具。装备加成应改变，角色永久修正不消失、不变成两份。
4. 选择最大 HP，先“HP −10”，增加上限后当前 HP 不会自动回满。降低上限时仅在当前 HP 超出新上限才截断。“HP/SP 回满”恢复到新上限，已有状态仍保留。

## 经验、等级和身份

1. 点击“经验 ＋100/−100”，查看累计经验和距升级经验；达到标准阈值时升级。点击“等级 ＋1/−1”，累计经验定位到该等级阈值，属性读新等级参数表，不自动治疗。
2. 标准职业有学习表时，升级跨过的特技应出现在特技列表；降级不自动遗忘。自定义 Ruby 升级方式/公式不作为此项判定依据。样例学习表不适合观察时可参考独立标准夹具测试记录。
3. “姓名/职业/角色图”打开表单。修改姓名并“应用姓名”，状态/菜单摘要同步；输入 X/Z/空格不应误关闭，Esc 只先关闭表单。
4. 选择有效职业并“应用职业”。不兼容装备放回背包，等级/经验/已学特技保留；库存已满无法收回时明确拒绝整次修改。测试装备沿用所有有效职业可用规则，不能用它单独判断正式职业限制。
5. 使用工程已有 `Graphics/Characters` 图名（不必带扩展名），选择色相 120 并应用。菜单角色图及返回地图后的玩家应同步变色；地图位置/朝向不变。不存在的图名应拒绝，不用 RTP；空图名使用占位。

## 存档和生命周期

1. 修改永久修正和姓名/图像，返回主菜单 → 存档 → 空槽保存。
2. 返回标题 → 新游戏，修改应重置；返回标题 → 继续游戏 → 刚才槽位，永久修正/姓名/职业/等级/经验/HP/SP/图像应恢复，不重复获得测试物资。
3. 每次打开/关闭工具后回到原地图，坐标、朝向和地图事件开关不被重置。对话、诊断或事件执行期间仍不能打开菜单。
4. 可在 `data/test_setup.json` 将 enabled 改 false 后重启并新游戏：测试工具入口及额外发放消失，正式菜单和已有商店事件仍可用。不要因此修改测试定义或数据库后期望旧指纹存档继续读取。

## 列表滚动回归

1. 测试商店 → 购买，下滚到光标固定在末行并列表已经向上滚过；按一次上键，文字应保持不动、光标向上移一行。
2. 继续上移至可见首行，再按上键，才滚动列表。出售、背包和特技列表行为相同；数量界面取消后返回原商品和视口。
3. 默认测试商店只有 9 类商品，在较高窗口下可能全部可见。若无滚动，可临时使用 640×480 逻辑尺寸；不要把“尚未超过可见行数”当作滚动失败。自动测试另使用长商品/物品/特技列表，三种尺寸截图包含长列表对比。

## 旧功能

用药扣数量、装备预览/取消、特技只读与原动画多实例、商店确认/取消、State 增删查询及四槽位存读档应保持正常。听感、键盘手感与实际工程特定资源需人工确认；自动截图使用 Dummy 音频。性能是当前电脑短测目标，不代表所有工程每一帧都锁 60。
