# RGMigrator ver0.18 人工验收清单

ver0.17 默认功能已由用户验收。ver0.18 补齐原生人物移动、地图交互及测试入口；分类素材接口沿用，不新增事件指令或自动转换 Ruby。以下是本版验收，不要求原魔塔脚本玩法恢复。

## 准备

1. 新版迁移器重新迁移到新的空目录，勾选“准备测试物资”；不覆盖原已验收工程。
2. Godot 标准版打开输出 project.godot，等待资源导入，运行 → 新游戏。遇到旧事件的未支持指令诊断可关闭；不应出现新增脚本错误或资源导入闪退。
3. 在真实原地图检查移动，再 Esc → F6 → **人物与地图**。至少检查 640×480；800×480、768×768 可用于布局与负载，不要求更改源 RM 工程。

## 原地图：移动与返回

- [ ] 方向键平滑四方向行走，不是整格闪现；使用原 Characters 四方向四帧和角色色相。
- [ ] 撞墙或人物不能穿过，可正常转向；碰撞不加步数，走完一格加一步。
- [ ] 行走中按 Esc/X：本格走完再进入菜单。返回同一地点、朝向，不重载地图或重跑启动事件，不停在半格。
- [ ] 普通菜单暂停人物/自动图块/地图动画，背景音乐保持；返回继续。对话/诊断期间不能打开菜单。
- [ ] 边界镜头不跟随人物露出地图外区域；地图小于窗口时居中。前景遮挡按人物脚点和图块优先级变化。
- [ ] 已支持的确认、触碰、传送仍工作；不能通行的方向不会误触发脚下触碰事件。未支持指令仍给出定位诊断。

原样例可能有空地图或未补全的启动事件，不将它们当作所有移动测试的唯一样例；下面独立验收区保证有可操作内容。

## F6：独立验收区

方向键移动，Z/Enter/Space 交互，Q 跳两格；按钮可点击，也可 Tab 选择、F5 执行。起点 (2,4)，仅预览运动不加真实步数。

- [ ] 外圈灰墙阻挡；勾选“穿透”后可进入墙格，但不能离开 12×9 边界。取消后恢复正常通行。
- [ ] 速度 1 和 6 明显不同；“回到起点”取消当前运动并回到 (2,4)。不影响真实地图坐标。
- [ ] 勾选“方向固定”：可以朝不同方向走，但人物朝向不变。取消后随移动转向。
- [ ] 勾选“踏步”：原地持续切换帧。关闭踏步、关闭“行走动画”：行走不切帧；重新开启恢复。
- [ ] 草丛在 x=2–4、y=2–3；脚下显示地形 7，人物下方 12px 半透明，上半身仍清晰。
- [ ] 红格 (2,6) 禁止向右，(3,6) 也不能向左进入；其他许可方向可通行。
- [ ] 到 (5,5)，朝上按确认：隔着柜台报告“事件 #1”；柜台本身不能走入。靠近 (7,6) 的人物按确认也报告事件。
- [ ] 到 (2,7) 报告触碰点。验收区只报告结果，不执行其事件指令、不修改原数据库。
- [ ] 黄色遮挡图块 (8,2)/(9,2)：人物在背后被盖住，向南走到前面时显示在上方。可从下方接近查看。
- [ ] Q/“跳跃两格”：有抛物线，落在合法位置；允许跨障碍，不允许落到墙、人物或地图外。跳跃不加真实步数。
- [ ] 整张测试地图在 640×480 下可见，中文、选项、底部结果和返回按钮可读；Esc/X 逐级返回。

## 应用、存档与隔离

1. 预览速度 6 或踏步，先直接返回：真实玩家选项不改变；位置、步数、背包和开关变量不改变。
2. 再进入设置，点“应用到玩家”后返回：真实玩家使用新选项，位置不被传送到测试区。
3. 普通菜单存档 → 返回标题 → 继续游戏：位置、朝向、速度/踏步等选项恢复，不重复发测试物资；彻底关闭重开也应一致。
4. 再次新游戏：人物选项恢复默认。测试区“恢复默认”只改预览，需再次应用才修改真实玩家。
5. 正式模式取消测试准备：不出现 F6 工具，原生人物接口仍可调用。

## 回归与边界

- [ ] 菜单、物品恢复、换装、技能学习/查询与动画并发、商店、State、角色成长、四槽位存档及图片/屏幕仍正常。
- [ ] 没有 RTP 补取、Ruby 自动执行或新增事件指令。自主移动/强制路线/并行与完整事件调度仍留到 ver0.2–0.3。

自动检查和本机性能证据见 [验证记录](VERIFICATION_v0.18.md)。60 秒平均和 P95 是场景统计，不保证逐帧锁 60，也不替代手感验收。
