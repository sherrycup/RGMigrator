# RGMigrator ver0.13 人工验收清单

验收目标：特技学习状态、事件接入、只读列表与独立动画播放。技能效果、伤害、治疗、SP 扣除、公共事件执行和自定义 Ruby 技能注册不在本版范围内。

## 准备

1. 用 ver0.13 迁移器选择原 RMXP 工程，勾选“准备测试物资”，导出到新的空位置。
2. 用 Godot 打开新生成工程的 `project.godot`，等待首次资源导入完成后运行。
3. 点击“新游戏”。若原地图启动事件出现已有不兼容诊断，点击“关闭”后再打开菜单。
4. 操作：方向键选择，Enter / Space / Z 确认，Esc / X 返回。特技页底部的测试按钮使用鼠标点击。

## 必测项目

- [ ] **首次导入与启动**：Godot 导入阶段不闪退，可以打开标题并开始新游戏。查看迁移报告：未通过音频检查的原件保存在 `legacy/unsupported_assets`；不要把“原件保留”理解为它已能播放。
- [ ] **属性名称**：状态页及装备预览中的 `str/dex/int/atk/pdef/mdef` 分别显示“力量 / 灵巧 / 魔力 / 攻击力 / 物理防御 / 魔法防御”。更名后属性值和换装结果仍正常。
- [ ] **特技入口**：地图按 Esc → 特技（源工程可能用其他命令名称）→ 选择角色。已学列表显示名称、图标、说明、SP 参数；测试模式显示 ID。
- [ ] **自动准备**：列表包含“测试用·动画特技”“测试用·共用动画”“测试用·无动画特技”。还可能显示原职业学习表授予的特技，这是正常情况。
- [ ] **只读行为**：记下角色 HP/SP，在列表按确认键后数值不变，没有治疗、伤害、扣 SP 或公共事件触发。
- [ ] **遗忘**：点击“遗忘测试特技”，“测试用·无动画特技”从该角色列表消失。再点一次仍正常，不影响另两个测试特技。
- [ ] **学习**：点击“学习测试特技”，刚才的特技重新出现。重复点击不产生重复行。两个按钮通过真实事件指令 318 修改角色状态。
- [ ] **有动画**：选择“测试用·动画特技”，点击“预览动画1”和“预览动画2”。能看到光环动画正常推进、结束；播放前后 HP/SP 不变。
- [ ] **共用动画**：选择“测试用·共用动画”，点击“预览动画1”。应能播放同一个光环，表明动画可被多个技能引用。
- [ ] **无动画**：选择“测试用·无动画特技”，点击任一预览按钮。应提示未配置动画，界面继续响应，没有报错或播放先前的残留动画。
- [ ] **返回与清理**：播放期间按 Esc，先关闭预览；继续按 Esc 返回角色选择、主菜单、地图。位置/朝向不变，药品库存、换装结果和已学特技保持；再次打开列表可以继续使用测试按钮。
- [ ] **新游戏重置**：遗忘测试特技后，经“结束游戏 → 返回标题 → 新游戏”，三个测试特技恢复初始配置且不重复累加；药品、装备也按既有规则重置。
- [ ] **旧功能回归**：药品恢复/消耗、装备预览/更换/卸下、状态页、菜单返回地图、返回标题和退出均正常。

## 配置开关检查

- [ ] 停止游戏，在新导出工程的 `data/test_setup.json` 中把 `enabled` 改为 `false`，保存后重新运行并开始新游戏。不再额外授予测试特技、药品和装备，特技页没有预览/学习/遗忘测试按钮。原职业初始特技仍可显示。
- [ ] 测完可改回 `true`。这一检查只改导出工程配置，不需要修改原 RM 工程或重新迁移。

## 画面检查

- [ ] 在实际使用分辨率下，中文、图标、光标、说明和底部按钮可见，不被裁切；列表可滚动。
- [ ] 动画结束或返回地图后，没有残留闪光、隐藏的角色或挂在画面上的动画单元。
- [ ] 对原工程中已有的“显示动画”事件，如可直接到达，检查玩家/指定事件上的位置与播放表现；带音效的动画检查音效同步。没有可到达的事件时，不必为了人工验收回 RM 新增事件。

## 已由自动测试检查的接口和边界

`learn_skill`、`forget_skill`、`has_skill`、`get_skill_ids`；初始职业学习表、离队角色和加入初始化、重复操作、独立 ID 数组、数据库不变；事件 318、111 的“角色已学特技”真/假分支；207 的玩家/当前事件/指定事件目标；无效引用定位及中断；动画单元、时间推进、条件时序、并发闪光恢复与节点清理。

这些结果见 `VERIFICATION_v0.13.md`。人工验收仍以实际操作与画面为准。
