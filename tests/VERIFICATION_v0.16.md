## 角色属性与成长

独立标准夹具使用随等级增长的六行参数表、武器/盾加成、两种状态倍率及职业学习表，不把魔塔样板的自定义数值当作默认规则。

- 九项参数来源分开，base 包含数据库与装备、角色 plus 初始零；卸装/重装保留永久修正且不重复累计。防御合计、武器 ATK、空装备与不读取自定义装备 HP 字段均验证。
- 原生属性 str/atk/maxhp/exp/name 写入与 RuntimeState 共用接口；来源快照为独立副本。数据库保持不变。
- 最终赋值在 200% 状态下精确反推修正；不可达奇数目标、零倍率、小数/NaN/无穷、上下界和未知属性拒绝且不部分修改。永久增量与最终增量分开测试。
- HP/SP 赋值截断至当前上限；上限降低截断、提高不治疗；recover_vitals 只回满并保留轻量状态，不执行触发效果。
- 经验阈值、直接 EXP 增量、跨级学习、降级保留技能、负经验截零、经验上限、满级和无下级经验通过。坏目标参数表/坏学习引用不部分提交成长。
- 姓名、角色图/色相、空图像及坏图像输入通过。职业变更收回不兼容装备，即使固定槽也可因职业解除；库存满则职业、装备、背包整次不变。保留等级/经验/技能和永久修正。
- 离队后变更、普通加入保留、初始化加入重置通过。真实样例用 Esc/F6/Enter 打开并执行，X 在文本框内可输入，Esc 先关表单，再返回工具和主菜单；三个鼠标入口分别指向正确工具。正式模式不开放入口。
- 返回原地图验证实例 ID、坐标、朝向保持；运行时色相更新原玩家材质，不重新加载地图。样例升级若新等级上限变低，当前 HP 可降低，这是截断而不是自动治疗；测试按这一标准判定。

## 768×768 性能

最终布局在预热后交替 Map585 与物品、装备、技能预览、存档槽、原动画双位置、商店、状态工具、角色成长工具，每 3 秒切换，关闭垂直同步。测量时仅本次 Godot 测试进程运行，未结束用户进程。

60 FPS 上限，**60.002182 秒 / 3591 帧**：平均 **59.848 FPS**、P95 **17.789 ms**，达到平均 ≥59 / P95 ≤20 ms。节点 **101→101**、资源 **76→76**、显存 **41,406,286→41,406,286** 字节，静态内存 **118,976,181→119,064,545** 字节。短测没有节点/资源数量累积，不代表长期绝无泄漏。原始证据 `v016-final-sample2/menu-benchmark.json`。

不限帧补测 **30.00109 秒 / 9344 帧**：平均 **311.455 FPS**，帧间隔 P95 **6.022 ms**、P99 **7.282 ms**、最长 **102.141 ms**；超过 16.667 ms 的比例 **0.11772%（11 帧）**。不能宣称每一帧稳定 60 或绝无卡顿，本轮未采集这些长间隔的完整主线程调用栈，不能武断归因。

引擎渲染计时可用，渲染 CPU（准备加视口）P95 **3.400 ms**、视口 GPU P95 **2.389 ms**；不是完整脚本/引擎成本，也不能相加当作总帧时长。限帧帧间隔包含等待和调度。证据 `v016-final-sample2/menu-uncapped.json`。首轮布局测量另保留在 `v016-sample2/`，最终数字使用修正后的测量。

## 边界

本版为原生标准数据接口，不执行或转换 Ruby，不恢复魔塔自定义属性映射/成长/战斗，不新增地图事件指令、永久属性物品效果或 State 触发底层。数据库/地图编辑器、RTP 和 RM 旧存档仍不属于本版。自动画面测试用 Dummy 音频；听感、手感及完整工程玩法仍需人工验收。
