# RGMigrator ver0.14 人工验收清单

范围：新工程存读档、标准装备槽名称、原工程动画与多实例播放。没有增加战斗、技能效果、Ruby 自动转换或旧存档读取。

## 准备

1. 用 ver0.14 重新迁移到新的空目录，保留“准备测试物资”勾选；已有已验收工程不会自动升级。
2. 用 Godot 打开输出的 `project.godot`，等待导入完成后运行并点击“新游戏”。原启动事件若提示不兼容，先关闭诊断，再打开菜单。
3. 菜单用方向键选择，Enter / Space / Z 确认，Esc / X 返回；原动画测试入口及按钮使用鼠标。
4. 本次不改变出生地图。若仍使用初始化 Map002，地图移动回归请在你已有可行走起点测试；不要求为本版回 RM 新增事件。

## 核心：保存 → 真正退出 → 继续游戏

- [ ] 新游戏中使用一瓶血瓶，记下 HP 和库存；装备测试铁剑或钢剑，记下装备和攻击力；在特技页遗忘“测试用·无动画特技”。如地图可行走，移动几格并改变朝向。
- [ ] Esc 返回主菜单 → 存档。能看到四个槽位；选择空槽位确认后显示保存成功、队伍、地图、保存时间与游戏时间。返回地图，进度没有重置。
- [ ] 返回标题后“继续游戏”可用；直接关闭游戏，再重新运行，继续游戏仍可用。
- [ ] 继续游戏 → 选择刚才槽位 → 确认。回到保存的地图和位置，朝向、HP/SP、库存、装备、已学特技、金币、步数和时间保持。不会重复发药品或重新学回被遗忘的测试特技，不再重放进入地图的启动自动事件。
- [ ] 保存两个不同进度到不同槽位，分别读取能得到各自的状态；一个槽位的操作不影响其他槽位。
- [ ] 保存至已有槽位时先询问覆盖，默认选“取消”；Esc 或确认取消不改变原文件。确认覆盖后，下次读取为最新进度。
- [ ] 读档后返回标题 → 新游戏，仍按新游戏规则重置测试物资与角色状态，不把存档内容当作默认开局。

## 装备栏与旧功能

- [ ] 状态页、装备槽列表从上到下统一显示：武器、盾、头部防具、身体防具、饰品。名称完整可见。
- [ ] 血瓶恢复/消耗、换装/卸下/预览、特技学习/遗忘、菜单逐级返回、地图移动和退出仍正常。
- [ ] 字体、皮肤、光标和确认框不被裁切；窗口更大时布局正常。存档失败时有明确原因，而不是假装成功。

## 原动画和并发

特技列表 → “原动画/并发”。这里列出原工程 Animations 的 ID 和名称，使用原动画图像及帧数据，不是三个测试特技的程序绘制光环。

- [ ] 选择一个素材完整、位置为目标头部/中心/脚部的动画，点击“左侧播放”和“右侧播放”，在相应目标上播放；没有素材时明确诊断，不补取 RTP。
- [ ] 点击“双位置同时”，能看到左右两处同时播放，活动实例数至少为 2；两者独立结束。画面位置动画按原定义出现在屏幕中心，不能用它判断左右定位是否正确。
- [ ] 点击“同目标叠加”，或在第一个尚未结束时再次点击“左侧播放”。活动实例数增加，第一个不会被第二个取消。
- [ ] 第一个动画还在播放时切换到另一个动画 ID，再点击“左侧播放”。第一个继续，第二个新增。若动画会隐藏目标或闪光，先选普通动画，避免把视觉重叠误认为实例消失。
- [ ] 动画结束后活动实例数回到 0；“停止全部”或 Esc 返回能清理动画、闪光/隐藏状态，不改变 HP/SP。测试页最多 32 个实例用于防误点击，不是地图的单实例限制。
- [ ] 对源工程可直接到达的显示动画事件，可检查连续播放指令的实际效果；没有可到达事件时，不要求为验收回 RM 修改工程。带音效的动画需要另外检查实际听感。

## 可选：备份和异常保护

自动测试已覆盖这些边界，不要求你破坏正式存档。想人工复核，请仅对可丢弃测试槽位进行操作，先复制整个存档文件夹备份。

- [ ] 同一槽位成功保存两次后出现 `slotN.json.bak`。只把主文件改名保留，标题槽位显示“备份”；必须确认读取，恢复的是上一份保存的进度。测试后将主文件改回，不要删除原件。
- [ ] 损坏或不兼容槽位显示原因；没有任何有效槽位时继续游戏灰显。失败不会改变当前游戏进度；不会把旧 RM 的存档当作新格式读入。
- [ ] 原工程已存在的“禁止存档”状态会灰显入口，底层拒绝写入。事件/对话期间不能打开菜单；本版没有新增事件 352 唤出存档。

新存档使用项目专属 `user://rgmigrator_saves/<标识>/`，不写回 RM 目录或素材目录。修改数据库/地图/system 或测试定义会影响兼容性；只改测试库存数量、enabled 或初始比例，不会改写已有进度。当前 BGM/BGS 播放进度、运行中的事件和动画不保存。

自动测试和真实画面结果见 [验证记录](VERIFICATION_v0.14.md)。
