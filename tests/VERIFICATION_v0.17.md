## 本次实现与边界

- 增加 PictureState、ScreenState、PictureSprite、ScreenRenderer、ScreenTools；数据与显示节点分离，图片按编号 1–50 独立保存和绘制，纹理/着色器复用，素材按需加载。
- 图片显示/同号替换/擦除、原点、屏幕位置、独立缩放、透明度、正常/加算/减算混合、旋转和色调，支持按秒插值及覆盖当前过渡。正角度逆时针，速度为度/秒。
- 地图整体色调及水平震动、覆盖地图/图片的闪光；图片固定屏幕坐标，有独立色调，不随地图震动。对话/诊断/菜单/工具位于上层，不受这些效果污染。震动采用像素/Hz/秒与结束包络，不复制 RGSS 固定帧波形。
- 普通菜单/商店暂停效果，测试页在暂停地图输入时显式推进预览。传送保留状态，标题销毁显示节点，新游戏清空。screen 数据、旋转和剩余过渡时间进入现有 schema 1 存档，旧新格式缺字段默认中性。
- F6 工具可以选源 Pictures 素材和编号，直接进行双图/变换/色调/闪光/震动测试；另有代码绘制的对照色块，非 RTP。全部重置只清空图片/屏幕，不改地图、角色或背包。
- 不新增事件指令，不执行 Ruby；223–225、231–234 仍诊断并停止当前事件，235 原有擦除路径保留。天气、雾和其余地图表现尚未实现；事件系统安排在 ver0.2–0.3，ver0.2 前优先图片/屏幕及角色/地图。

实现分层参考样板 Game_Picture/Game_Screen 及 [RMXP 默认 Spriteset_Map 源码](https://github.com/orzFly/RPGMakerDefaultScripts/blob/master/rpgmaker-xp.en/Spriteset_Map.rb)，着色使用 [Godot CanvasItem shader 接口](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html)。原生接口不承诺同名 Ruby API 直接执行。

## 768×768 性能

采用 Map585 及九种菜单负载（物品、装备、技能预览、存档、原动画并发、商店、State、角色工具、双图移动/旋转/色调和屏幕效果）。预热后，地图/菜单每三秒切换，60 FPS 上限，vsync 关闭。

最终有效测量：**60.00542 秒 / 3569 帧**，平均 **59.478 FPS**、P95 **19.893 ms**，达到平均 ≥59 FPS、P95 ≤20 ms 的既定目标。节点 **109→109**、资源 **82→82**、显存 **52,331,490→52,331,490** 字节，静态内存 **120,048,088→120,137,388** 字节；短测没有节点/资源数量累积，不代表长期绝无泄漏。原始数据 `v017-verified-sample2/menu-benchmark.json`。

补充 30.003165 秒不限帧：4577 帧，平均 **152.551 FPS**、P95 **11.094 ms**、P99 **13.668 ms**、最长间隔 **188.427 ms**，超过 16.667 ms 的间隔比例 **0.328%**。渲染 CPU（准备加视口）P95 **6.256 ms**，GPU P95 **4.648 ms**，GPU 计时可用。不是完整脚本/引擎成本，也不能相加当作总帧耗时。证据 `menu-uncapped.json`。

本次成绩有余量限制及长间隔边界，**不宣称逐帧稳定 60**，不把最长间隔未经分析地归因给某个模块。此前色调按钮未启用时的 59.905 FPS 测量不是最终有效负载，不作为交付数字。
